79 // This is a semi-public API to check if the corresponding instance has been constructed with a
80 // holder. That is, if the instance has been constructed with a holder, the `__init__` method is
81 // called and the C++ object is valid. Otherwise, the C++ object might only be allocated, but not
82 // initialized. This will lead to **SEGMENTATION FAULTS** if the C++ object is used in any way.
83 // Example usage: https://pybind11.readthedocs.io/en/stable/advanced/classes.html#custom-type-setup

85 // WARNING: The caller is responsible for ensuring that the `reinterpret_cast` is valid.
